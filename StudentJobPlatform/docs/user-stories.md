# User Stories

## Student
- Si student, dua të shoh listën e punëve part-time në mënyrë që të gjej një punë të përshtatshme.
- Si student, dua të aplikoj në një punë në mënyrë që të kem mundësi punësimi.
- Si student, dua të përditësoj profilin tim me aftësi dhe lokacion.

## Employer
- Si punëdhënës, dua të postoj vende pune part-time në mënyrë që të gjej studentë për punë.
- Si punëdhënës, dua të shoh aplikimet e studentëve për vendet e mia të punës.

## Admin
- Si admin, dua të menaxhoj sistemin dhe përdoruesit.
